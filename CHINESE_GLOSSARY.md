# Chinese Glossary

This file records approved terminology and unresolved translation decisions for
the Simplified Chinese edition. It is a working glossary, not a full copy deck.
`CONSTITUTION.md` remains the higher authority.

## Approved Terms

| Concept | Approved form | Notes |
| --- | --- | --- |
| Chinese name | `叶锦华` | Use as the primary Chinese site name. |
| English name | `Jinhua Yip` | Keep for English identity and external references. |
| Public Chinese prefix | `/zh` | User-facing path prefix. |
| Internal locale | `zh-Hans` | Internal locale id for routing and content. |
| English routing | unprefixed | English remains at `/`, `/about`, `/projects/[slug]`, and so on. |
| Surface CTA | `下潜` | Homepage dive action. |
| Sea of Consciousness | `意识之海` | Approved Chinese name for the homepage concept. |
| Site title | `叶锦华｜研究与项目` | Use for Chinese metadata and title surfaces. |
| Portfolio description | `研究与项目` | Site and metadata description of the portfolio. |
| Archive navigation label | `项目` | Use for archive/projects navigation. |
| Methodology and limits | `方法与局限` | Approved reader-facing phrase. |
| Source-backed | `有据可查` | Approved where context permits. |
| Source record | `来源条目` | Provisional, but approved for UI use. |
| Evidence confidence | `证据可信度` | Use when confidence is not a statistical interval. |

## Banned Terms

| English source term | Do not use | Reason |
| --- | --- | --- |
| semiconductor tooling | `工具链` | This misstates the domain. Tooling here refers to semiconductor equipment, production steps, and manufacturing capability, not a software toolchain. |

## Unresolved Terms

These terms still need approval before they become public copy.

| English term | Status | Notes |
| --- | --- | --- |
| individual atlas translations | unresolved | Do not approve atlas-by-atlas Chinese names until a copy file records them. |
| semiconductor tooling | unresolved | Must not become `工具链`. Choose a term that can cover equipment makers and production steps without sounding like software infrastructure. |
| claim status | unresolved | Must describe the status of a claim: confirmed, reported, projected, or mock. |
| project-specific methodology terminology | unresolved | Approve per project when the project copy is written. |

## Project Title Rule

Do not finalize individual Chinese project titles unless they are explicitly
approved in `docs/i18n/CHINESE_COPY_V0.md` or a later approved copy file.

For Phase 1, keep current English project titles on Chinese project pages unless
approval has been recorded.
