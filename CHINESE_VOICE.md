# Chinese Voice

This is the Simplified Chinese companion to `VOICE.md`. `CONSTITUTION.md` is
still the source of truth. If this file conflicts with `CONSTITUTION.md`, the
constitution wins.

This document is an editorial guide, not approved public page copy.

## Core Stance

The Chinese edition should read like a careful analyst writing for a serious
reader. It should be concise, specific, calm, and source-honest.

The voice is not marketing Chinese. It should not sound like a platform launch,
a startup landing page, a generic developer portfolio, or a translated slogan.

## Two Registers

- The globe, dive, Sea of Consciousness, and ambient-thought layer may use
  restrained poetic or fragmentary language.
- About, Research, project pages, methodology, sources, and analytical products
  should use direct and concrete Chinese.

The front door can feel atmospheric. The reading room should stay plainspoken
and exact.

## Voice Rules

- Write short, claim-bearing sentences.
- Prefer precise nouns and verbs. Name the object, method, source, filter,
  status, or uncertainty.
- Explain what the reader can inspect: sources, weights, filters, assumptions,
  gaps, sensitivity tests, or current status.
- Separate evidence from interpretation. If a claim is announced, estimated,
  confirmed, or uncertain, say that plainly.
- Use first person on personal pages when it sounds natural.
- Use a neutral analytical voice for atlas, methodology, project, and evidence
  copy.
- Keep long editorial prose in locale-specific typed content files, not messages
  JSON.
- Use messages JSON only for short UI strings.
- Translate intent, not syntax.

## Avoid

- Generic localization filler, including vague phrases like "explore the
  landscape", "unlock insight", "empower decision-making", or their Chinese
  equivalents.
- Hype adjectives that praise the work instead of showing what it does.
- Ornate slogans, manifesto language, literary flourishes, and decorative
  parallelism.
- SaaS or platform language: do not make the site sound like a product funnel.
- Repeated Chinese em dashes used to imitate English prose. Use an em dash only
  when it reads naturally. Prefer short sentences, colons, semicolons, or line
  breaks.
- One generic description reused across all projects.
- The same "开放式研究图谱" description reused across projects.

## Term Judgment

- Do not treat `收录` or `涵盖` as universally forbidden. Avoid them by default,
  but allow them when the text genuinely describes archival inclusion or scope.
- Do not use `研究员` as Jinhua's title unless a specific employment context
  requires it.
- On the About page, use `做科技政策研究`.

## Project Copy

Every project needs its own Chinese description. The description should state
what the project is, what the reader can inspect, and what evidence limits still
matter.

Do not finalize Chinese project titles unless they are explicitly approved in
`docs/i18n/CHINESE_COPY_V0.md` or a later approved copy file.

Until a Chinese project title is approved, keep the English title.
